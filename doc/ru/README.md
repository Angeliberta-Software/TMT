# TMT - Talking Meta Trader

Плагин NVDA для Meta Trader 5.

Позволяет перемещаться по Meta Trader 5 с помощью горячих клавиш.

Также это дополнение может считывать данные графика из MetaTrader и озвучивать их звуковыми тонами, помогая незрячим пользователям понимать тренды, уровни и фигуры.

## Требования

* Последняя версия Meta Trader 5 x64.
* NVDA 2026 и выше.

## Основная навигация

### Фокус

* Control+1: окно панели инструментов.
* Control+Shift+1: фокус на списке вкладок панели инструментов. После установки фокуса используйте объектную навигацию NVDA влево и вправо, чтобы выбрать вкладку.
* Control+2: окно данных.
* Control+3: окно навигатора.
* Control+4: окно обзора рынка.
* Control+5: рабочее пространство.

Соответствующие флажки должны быть включены в меню View, и все панели должны быть видимы.

### Озвучивание

* Control+P: текущий профиль.
* Control+0: текущее время в терминале.
* NVDA+T: озвучивает инструмент активного графика вместо длинного номера счета и названия компании.

## Чтение графика

Откройте новый график или переключитесь на вкладку с графиком, который вы хотите читать.

Используйте клавиши "Q" и "E", чтобы слышать бары в виде звуковых тонов.

Используйте "Q" для перемещения влево (назад) и "E" для перемещения вправо (вперед).

При каждом переходе от бара к бару вы услышите два тона:
* Первый тон соответствует цене открытия.
* Второй тон соответствует цене закрытия.

Если включена опция "Play high/low" (Control+C), вы услышите четыре тона вместо двух:
* Для медвежьего бара (цена закрытия ниже цены открытия): открытие, закрытие, максимум и минимум.
* Для бычьего бара (цена закрытия выше цены открытия): открытие, закрытие, минимум и максимум.

Для перемещения вперед и назад, а также для озвучивания числовых значений цен используйте следующие комбинации клавиш:

### Сочетания клавиш для чтения графика

#### Навигация

- **Ctrl + Shift + I** - озвучить текущий график и таймфрейм.
- **Ctrl + Shift + Q** - перейти к первому бару.
- **Ctrl + Shift + E** - перейти к последнему бару.
- **Shift + Q** - переместиться на 5 баров назад.
- **Shift + E** - переместиться на 5 баров вперед.
- **Ctrl + Q** - переместиться на 12 баров назад.
- **Ctrl + E** - переместиться на 12 баров вперед.
- **Q** - перейти к предыдущему бару.
- **E** - перейти к следующему бару.

#### Информация о цене

- **A** - озвучить цену открытия.
- **D** - озвучить цену закрытия.
- **S** - озвучить минимальную цену.
- **W** - озвучить максимальную цену.
- **F** - озвучить дату.
- **V** - озвучить объем.
- **C** - озвучить текущую цену.

#### Линейка

- **Ctrl + S/W/A/D** - установить начальную точку линейки. Если точка задана, будет озвучена разница в цене и количество баров между точками.

#### Маркеры

- **M** - установить маркер.
- **Shift + M** - удалить маркер.
- **]** - перейти к следующему маркеру.
- **[** - перейти к предыдущему маркеру.

#### Уровни

- **Shift + S/W/A/D** - установить уровень.
- **Shift + L** - удалить выбранный уровень.
- **T** - следующий уровень.
- **G** - предыдущий уровень.
- **L** - ближайший уровень к текущей цене.

#### Другие функции

- **P** - воспроизвести предварительный просмотр.
- **Ctrl + C** - переключить "Play high/low".
- **Ctrl + L** - озвучить пересечение уровней.
